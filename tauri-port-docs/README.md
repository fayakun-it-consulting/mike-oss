# Tauri Port Documentation

This folder contains the findings and decisions related to converting the current
project (frontend + Express backend) into a **stand‑alone Tauri application**.

## Overview

| Item | Status | Notes |
|------|--------|-------|
| **Frontend** | Next.js (React) | Will be built into static assets and served by Tauri. |
| **Backend** | Express (Node.js) | Will be launched as a child process from the Tauri binary. |
| **Tauri Wrapper** | Rust (auto‑generated by `tauri init`) | Handles launching the backend, exposing IPC commands, and packaging. |
| **Runtime Alternatives** | Bun (Node‑compatible Rust runtime) | Only Rust runtime on the list that implements Node APIs. |
| **Pure Rust Engines** | Boa, Lumen, etc. | Do not provide Node APIs; would need custom shim. |
| **Final Decision** | Keep Express, launch via Tauri | Simplest path, minimal code changes. |
